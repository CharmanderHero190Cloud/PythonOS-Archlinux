# PythonOS-Archlinux
This is for archlinux system

# How to install Archlinux
1. Download Archlinux iso from everywhere
2. Flash it
3. Run it from PC/Laptop/Other
4. In grub press : first thing
5. Wait until shows Archlinux (tty1)
6. Then type archinstall
7. Connect to wifi
8. Set Everything but select in profile Minimal
9. Wait until install

# Connect to wifi again
Type nmtui
Connect to wifi

# Install Modules
1. sudo pacman -S nano
2. sudo pacman -S python

# Work Online
